# 王者荣耀 · 全英雄克制链

一个纯前端的王者荣耀英雄克制关系查询工具，单文件实现、零依赖、开箱即用。

## ✨ 特性

- **全英雄数据**：涵盖对抗路 / 中路 / 发育路 / 游走 / 打野全分路英雄
- **克制链可视化**：直观展示英雄之间的克制与被克制关系
- **单文件零依赖**：所有样式、脚本、英雄头像（内嵌 base64 图片）全部打包在一个 `index.html` 中
- **离线可用**：下载后双击即可在本地打开，无需联网
- **移动端适配**：手机浏览器访问体验良好

## 🚀 在线使用

启用 GitHub Pages 后，直接访问：`https://<你的用户名>.github.io/honor-of-kings-counter-chain/`

## 💻 本地使用

克隆或下载本仓库，用浏览器打开 `index.html` 即可：

```bash
git clone https://github.com/<你的用户名>/honor-of-kings-counter-chain.git
```
